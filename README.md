
# Hijabi Store - Modest Fashion E-Commerce

A modern, responsive E-Commerce web application built for modest fashion and scarves. This project focuses on high-quality UI/UX design, modular component architecture, and clean state management.

---

## Live Demo
Link: https://hijabi-store.vercel.app

---

## Tech Stack
- Framework: React.js (Vite)
- Language: TypeScript
- Styling: Tailwind CSS
- Icons: Lucide-react
- State Management: Context API (ShopContext)
- Deployment: Vercel

---

## Features (In Progress)
- Interactive Product Showcase: Dynamic product cards with category filtering.
- Wishlist & Cart Management: Seamless state handling for adding/removing items.
- Dynamic Navbar Badges: Real-time counter updates for saved items.
- My Items Portal: Filterable tab system for all saved and cart items with empty-state UI.
- Outfit & Color Matcher (Coming Soon): Interactive color palette assistant for matching outfits with hijabs.
